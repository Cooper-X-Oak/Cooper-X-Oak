# Structural templates

For each template, define its task, required regions, optional regions, responsive transformation, supported content growth, and prohibited uses.

## Template

- ID: `github-profile-evidence-landing-v1`
- Primary task: Identify Cooper Oak and open one credible public work.
- Required regions: Native identity, one primary anchor, three ordered project
  proofs, three principles, one repositories exit.
- Optional regions: One shallow editorial signature strip.
- Responsive transformation: Single semantic column; select a mobile signature
  composition; allow natural text wrapping; never shrink desktop UI.
- Content growth behavior: Selected work remains capped at three. New work
  replaces an item through a recorded evidence decision. Additional work stays
  on the repositories page or in native Pins.
- Applicable scenarios: Public GitHub Profile README for a builder whose work
  spans categories and has uneven but real proof maturity.
- Do not use when: A real-time console, monitoring dashboard, résumé, service
  funnel, project documentation page, or exhaustive repository directory is
  required.

## Prohibited templates

- Dashboard, admin console, control plane, command center, RPG character sheet,
  KPI landing page, equal-card portfolio grid, and module registry.
