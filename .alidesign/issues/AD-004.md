## Problem and intended outcome

The accepted Pixel Oak assets are visually adequate, but the surrounding
Profile is still the old one-column `image -> heading -> paragraphs -> rules`
document. It lacks a designed interface grammar, meaningful density changes,
and differentiated regions. Redesign the whole page around an editorial ledger
grid without editing either visual role.

## Applicable authority

- User instruction: change the overall design; do not change the existing SVGs.
- `AGENTS.md`: `profile.json` is the authoring source; generated files are not
  hand-edited; GitHub and `profile.html` are acceptance surfaces.
- Previous accepted run: Pixel Oak geometry, colors, and public content facts.
- GitHub/GFM: static, sanitized README surface with native HTML/Markdown and no
  project CSS contract.
- `$review-design-quality`: coherence, authenticity, responsive, semantic, and
  anti-template checks.
