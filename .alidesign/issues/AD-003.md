## Problem and intended outcome

The current candidate is technically correct but visually rejected: its abstract
glyph does not read as Oak, the pixel language does not govern the page, and the
result reads as default Markdown with two decorative strips. Rebuild it as a
recognizable pixel Oak monument and an extreme-minimal visual poster without
fabricating an application interface.
