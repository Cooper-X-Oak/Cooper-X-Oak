# Selected art direction — Pixel Oak monument

The selected direction is a large, right-weighted 3:2 pixel poster followed by
native GitHub Markdown. A mature stepped Oak is the dominant identity object;
its shallow internal facet is a quieter forest-family material plane. The
poster uses flat opaque cells, substantial negative space, one optical signal,
and no typography, interface chrome, gradients, shadows, dashboards, terminal
motifs, badges, or fake controls.

The D03/D04 production projection is frozen by the canonical hashes and tokens
in `visual-design-spec.md`. Light and dark are theme projections of the same
geometry, not separate concepts. The Evidence chapter remains the only black
field and uses a root crop from the same Oak system.

This direction addresses the rejected v1 result by making the visual system a
large part of the first screen instead of a small glyph above otherwise plain
text. GitHub's native headings, links and responsive reading order remain the
semantic layer.
