# Oak structure-plane concepts

Generated deterministically by `render_oak_structure_concepts.mjs` from one
outer Oak silhouette, one Hero composition, one token set, and three legal
structure-face parameter sets.

| Variant | Light | Dark | Structure area |
|---|---|---|---:|
| 01 / Shoulder-weighted | `01-shoulder-weighted-light.svg` | `01-shoulder-weighted-dark.svg` | 87u² |
| 02 / Balanced | `02-balanced-light.svg` | `02-balanced-dark.svg` | 79u² |
| 03 / Grounded | `03-grounded-light.svg` | `03-grounded-dark.svg` | 82u² |

PNG files are local review projections of the corresponding SVG and are not
production assets. The SVGs are the deterministic concept sources.

All variants share:

- `54u × 36u` Hero viewBox;
- Oak bbox `(20u, 6u, 32u, 24u)`;
- bone/ink/forest/signal tokens locked by D03;
- one `2u × 2u` signal block;
- the same Oak silhouette and real Y/root negatives;
- one left-side structure-face topology.

The design controller must inspect the actual images and may reject the shared
outer silhouette even if all mechanical bounds pass. A valid generator is not
evidence of a good tree.
