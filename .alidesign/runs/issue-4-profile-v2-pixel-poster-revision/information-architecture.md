# Information architecture — offset full-tree poster

## Reading spine

```text
Hero poster / complete pixel Oak monument
H1 / COOPER OAK

Thematic break

  Question
  Hypothesis
  Evidence / three public proof links
  Next

  three public proof-linked statements
Thematic break
04 / Open loop
  one honest continuity statement and repository link
Thematic break
05 / Discuss on GitHub
  one counterexample context and action link
```

## Region responsibilities

- Hero: establish authored identity through a recognizable Oak, not through
  copy, data, or controls embedded in the SVG.
- H1 and lead: provide the complete native identity when images fail and
  semantically confirm the poster.
- Current experiment: state the bounded work and its public evidence without
  turning fields into cards or a status machine.
- Principles: expose three concise proof-linked operating commitments.
- Open loop: retain unfinished truth rather than simulate project completion.
- Discuss: provide the sole counterexample action.

## Poster continuity

The page uses one left reading axis below a right-weighted image. Stable folio
headings and one thematic break per top-level section maintain editorial
rhythm. No new image is required merely to decorate a section; any additional
visual role must carry a page-level compositional responsibility and be
separately approved.

## Responsive transformation

The Hero does not recompose through a mobile asset. At approximately 288px
content width, the fixed 3:2 image yields a roughly `171 × 128px` Oak while
preserving complete canopy, trunk, and roots. GFM remains one column and wraps
naturally. No element may create horizontal overflow.

## Failure path

When the image is missing or disabled, the image footprint collapses to a short
alt line, and the unique H1, lead, separator, and sections become the complete
page. The heading outline and link set remain unchanged.
