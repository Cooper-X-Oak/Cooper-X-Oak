# Profile v2 craft criteria

Status: canonical `craft` output for the static GitHub Profile.
Owner phase: `interaction_states`.

Motion is not applicable because the artifact is a static GFM document. Craft
remains required and is evaluated on the delivered README, preview, and assets.

## Composition and authorship

- Ring Ledger is one strong identity system, not an icon pack.
- Hero reads as intentional right-weighted counterspace at 860px and 320px.
- The exact heading sequence creates a visible editorial ledger without HUD,
  dashboard, terminal, portfolio-grid, or generic README regression.
- Evidence is the only author-defined black field; every other group relies on
  native heading hierarchy, whitespace, and three thematic breaks.
- Removing username and colors must not erase the project-specific relationship
  between capability routing, sealed evidence, the open loop, and counterexample
  feedback.

## Typography and content

- All meaningful copy remains native GFM and selectable.
- One H1, four ordered H2s, and four ordered experiment H3s only.
- No micro text, all-caps eyebrow system, slash numbering, terminal prompt,
  badge, fake status, fake metric, invented maturity, or duplicated copy.
- Claims use the maturity boundaries in `claim-proof-map.md` and public links.
- English leads. `提交反例` is the one concise Chinese action and is not repeated
  as an English duplicate CTA.

## Color and asset craft

- Only the six registered visual tokens may appear in generated SVG/preview
  roles; README itself inherits GitHub colors.
- Key Ring geometry meets 3:1 non-text contrast against its field in both themes.
- Light/dark files are structurally identical after registered color values are
  normalized.
- SVG uses flat square paths/rectangles only: no font, gradients, filters,
  shadows, blur, animation, remote resources, rounded chrome, or controls.
- Generator output is deterministic across two independent renders.

## Responsive and failure behavior

- Validate approximately 860px and 320px in light and dark themes.
- No horizontal scroll, crop, illegible shrinkage, or fixed-height text loss.
- Hero glyph remains at least 30% of the signature width and 65% of its height.
- Broken/hidden images preserve the same heading outline and link set.
- Every link remains a real keyboard-focusable anchor in document order.
- Static output has no custom loading, hover-only content, motion, or script
  dependency. Native GitHub/browser focus and visited states remain intact.

## Release evidence

- Contract tests and generator drift check.
- Deterministic asset hashes and structural-equivalence check.
- SVG XML parse and prohibited-content scan.
- README outline/link/asset-role inspection.
- 860-light, 860-dark, 320-light, 320-dark, and image-fallback screenshots.
- Public link requests, git diff, and `git diff --check`.
- Independent design review in a context separate from author and gate resolver.
