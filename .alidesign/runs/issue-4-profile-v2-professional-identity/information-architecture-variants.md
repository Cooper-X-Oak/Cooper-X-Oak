# Profile v2 information-architecture variants

Status: compared during the sequential user-decision round.
Basis: `decision-contract.md`, GitHub/GFM constraints, and real content maturity.

## Variant A — Evidence before method

```text
Identity / lead
→ Current Experiment
→ Working Principles
→ Open Loop
→ Discuss on GitHub
```

Strength: the public thesis receives immediate concrete evidence; principles are
earned by the experiment rather than presented as a manifesto.

Risk: the current case must be concise enough that the page still feels like a
Profile rather than technical documentation.

## Variant B — Method before evidence

```text
Identity / lead
→ Working Principles
→ Current Experiment
→ Open Loop
→ Discuss on GitHub
```

Strength: clear worldview and compact mental model.

Risk: unsupported-principle theater. A visitor must read claims about rigor
before seeing the work that justifies them.

## Variant C — Growth before method

```text
Identity / lead
→ Current Experiment
→ Open Loop
→ Working Principles
→ Discuss on GitHub
```

Strength: creates a stronger present-versus-past story.

Risk: the old repository can dominate the identity and make the page feel like
an explanation of unfinished work.

## Selection

The user selected **Variant A**. It best supports the approved primary action
`view the current experiment`, keeps the three principles evidence-bearing, and
limits the growth story to one honest Open Loop.
