## Evidence method

- GitHub profile and repository metadata were re-read for v2 rather than copied
  forward as current truth from v1.
- Relevant repository READMEs, release metadata, install paths, topics, and
  visible source/test structures were inspected.
- `profile.json`, current generated surfaces, the merged v1 run, and v1
  evaluation were inspected as repository evidence.
- A repository description is a lead. A release, installer, test, validator,
  runnable example, or documented boundary is stronger proof.
- Forks are excluded from authorship claims unless a public contribution record
  is separately established.
