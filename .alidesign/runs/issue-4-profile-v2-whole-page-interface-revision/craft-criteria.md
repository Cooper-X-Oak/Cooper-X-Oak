# Craft criteria — whole-page editorial ledger

- The difference from the previous version is visible below the Hero without
  comparing copy: field/value relationships, operating strip, and closing
  matrix must have distinct silhouettes.
- GitHub-native table borders and surfaces are used as a square, restrained
  interface grid; no rounded card or fake-window language is introduced.
- Table cells use consistent label-first hierarchy. Short labels never compete
  with declarations; prose remains readable at 320px.
- The Evidence marker remains the only authored black field and interrupts the
  experiment ledger at the proof boundary.
- Principles read as three operating commitments, not badges or feature cards.
- The closing matrix clearly distinguishes unfinished truth from the single
  action; the CTA is the final focal link.
- Light/dark behavior is owned by GitHub native surfaces and frozen SVG theme
  projections; no custom theme styling is assumed.
- No visual asset bytes change. Any hash drift is a release blocker.
- At 320px: `scrollWidth === clientWidth`, all tables fit the viewport, all
  eight links remain in bounds, and no declaration is clipped.
- With images disabled, semantic structure and all links are unchanged.
